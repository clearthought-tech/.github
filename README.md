# clearthought-tech org defaults

Shared GitHub community health files for [clearthought-tech](https://github.com/clearthought-tech).

- **Issue template:** Delivery work item (description, acceptance criteria, agent requirements, recommended changes)
- Board: [Clearthought Delivery](https://github.com/orgs/clearthought-tech/projects/1) — set Product + Priority on the project after filing

This repo is **public** so private product repos can inherit the templates (GitHub requirement).
